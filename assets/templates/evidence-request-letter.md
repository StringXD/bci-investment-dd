# 尽调资料索取函(模板)

> 用途: 门禁阶段判定「继续」后, 一次性发出完整索取清单, 避免多轮挤牙膏式索证。
> 使用方式: 按标的资产属性勾选适用栏目, 删除不适用项; 未勾选但对方主动提供的, 归入「其他」并登记。
> 纪律: 本函为一次性清单, 不以「先给一部分」为起点。分批提供会系统性拖延尽调周期, 并使证据覆盖率长期低于判定门槛。

---

**致: [标的公司名称] 及 [法定代表人 / 融资负责人]**

**发件: [机构名称] 投资部** · **日期: [YYYY-MM-DD]** · **回复期限: [YYYY-MM-DD] (自本函送达起 10 个工作日)**

**事由: 关于 [标的公司] [轮次] 融资尽职调查的资料提供请求**

为完成本次尽职调查并按内部流程出具结论, 我方需要下列资料。请以电子文件形式提供, 并在文件名前加注本函编号前缀(如 `A-01_营业执照.pdf`)。涉及第三方保密义务的, 可先提供脱敏版本并说明脱敏范围, 我方按保密协议处理。

**资料状态说明**: 每项请标注「已提供 / 部分提供 / 无法提供」。无法提供的, 请说明原因与替代证明方式。**无法提供本身不是问题, 但未说明原因会被记入证据缺口, 并影响结论分级。**

## 附: 拒供情形的处理规则(内部使用, 发送时删除)

| 情形 | 处理 |
|---|---|
| 拒供核心权属或临床文件 | 记入证据缺口, 结论不得高于「观察」; 若涉及一票否决级红旗, 直接终止 |
| 只提供 BP 与路演材料 | 视为证据覆盖率为 0, 结论为「资料不足, 不出结论」 |
| 分批提供且首轮缺关键项 | 记录首次索证日与回传日, 作为流程指标写入报告附录 B |
| 提供脱敏版本 | 允许, 但须在报告中标明脱敏范围与由此产生的判断局限 |
