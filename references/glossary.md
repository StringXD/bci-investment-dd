## 技术路线

| 中文 | 英文 | 说明 |
|---|---|---|
| 脑机接口 | Brain-Computer Interface, BCI | 在脑与外部设备间建立直接信息通道 |
| 侵入式 | invasive | 电极植入颅内或皮层表面 |
| 半侵入式 | semi-invasive | 电极置于硬膜外等中间层 |
| 非侵入式 | non-invasive | 经头皮采集, 含 EEG、fNIRS 等 |
| 脑电 | Electroencephalography, EEG | 头皮或皮层电位记录 |
| 功能性近红外 | functional Near-Infrared Spectroscopy, fNIRS | 基于血氧信号的非侵入手段 |

| 局部场电位 | Local Field Potential, LFP | 神经元群体电活动 |

## 表述约定

报告写作时的统一口径:

- 「无创」与「非侵入」视为同义, 全文统一用「非侵入」。
- 「准确率」必须附任务定义与试次数, 单独使用不构成指标。
- 「进入临床」必须说明是 IIT 还是确证性临床, 两者不可混用。
- 「获证」指取得注册证, 「受理」指提交申请被接受, 两者不可混用。
- 「装机」指设备交付并安装, 不等于「在用」, 更不等于「复购」。
