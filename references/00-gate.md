# 前置门禁: 五个问题决定要不要往下做

> 阶段门禁: `SKILL.md` 阶段 0 开始前必读
> 与脚本契约: 本文件的 G0-01 至 G0-05 对应 `scripts/dd_score.mjs` 的资产门禁步骤(输出第一节), 红旗编号 RF-01 至 RF-05 对应 `RF_LIBRARY`

## 何时使用本文件

拿到一个标的的第一小时用。目的不是判断好坏, 而是回答两个问题: **要不要投入完整九维深挖**、**该用哪一把尺子量**。门禁阶段的误判代价最高 —— 用错口径, 后面每一维都会算错。

## 门禁一 实体三问(G0-01)

三件东西必须分开确认, 它们回答的是三个不同的问题:

| 形态 | 回答的问题 | 证据形态 |
|---|---|---|
| 样机 | 能不能做出来 | 实验室演示、原理验证记录、失败片段 |
| 产品 | 能不能稳定地给**陌生人**用 | 型式检验报告、院内连续多日实测、非原班团队的操作记录 |
| 商品 | 有没有人愿意付钱 | 中标通知、订单、回款、医保编码 |

演示视频证明的是科学可行性, 不是工程成熟度, 更不是商业可行性。三者混为一谈是这个赛道最常见的叙事技巧。

**判定规则**: 停在样机阶段 → 只做 D3(技术) 与 D9(组织) 快筛, 不做完整九维, 不出分级结论。到产品阶段 → 进入完整流程。

## 门禁二 资产属性五分类(G0-02)

不靠主观判断, 直接引监管判定。依据《脑机接口医疗器械产品分类界定指导原则》(国家药监局 2026 年第 24 号通告), 产品须**同时**具备四项核心技术特征:

1. 测量中枢神经系统(脑和脊髓)产生的神经信号
2. 可完成神经信号实时解码, 且解码输出的指令直接用于实现产品主要预期用途
3. 实现患者与外部设备之间的实时双向交互或闭环反馈
4. 以改善、修复或替代中枢神经系统功能为临床目的

四项缺一, 就不属于脑机接口医疗器械。据此分五类:

| 资产类别 | 判定条件 | 分类编码 | 适用估值族 |
|---|---|---|---|
| 医疗级·植入式三类 | 侵入式或植入式 | 12-00 | 期权法 + 器械收入法 |
| 医疗级·非侵入三类 | 非侵入, 用于疾病治疗或功能代偿、康复训练 | 09-00 或 19-00 | 期权法 + 器械收入法 |
| 医疗级·二类康复 | 非侵入, **仅**用于脑卒中肢体运动康复训练, **且未采用人工智能技术** | 19-00 | 器械收入法(传统商业逻辑) |
| 消费级·非器械 | 用于功能增强、娱乐交互、日常辅助等非医疗目的 | 无(须明确标注不用于医疗目的) | 消费品逻辑 |
| 科研服务工具 | 面向研究者而非患者, 不构成医疗器械 | 视具体形态 | 仪器收入法 |

两条容易踩的边界:

- **用了 AI 的卒中康复产品回到三类**。二类的前提是「非侵入 + 未采用 AI + 卒中肢体运动康复」三个条件同时成立。算法引入误判患者意图的风险, 会把管理类别推回三类。按二类路径做研发、定型后才发现应按三类申报, 是最高频的返工原因。
- **不适用医用软件编码**。安全有效性按整套系统评价, 仅有脑电分析功能、不实现实时解码与反馈的独立软件, 不在脑机接口编码范围内。

## 门禁三 闭环真实性(G0-03)

闭环链路五个环节, 缺任何一个都不能算完整闭环:

`采集 → 时空同步 → 实时解码 → 驱动外部设备 → 感觉或刺激反馈回到受试者`

监管口径把「仅具备单向信号采集或单向刺激功能」明确排除在外, 并点了两类名字: 脑电图机、不具备闭环反馈的脑深部刺激系统。行业口径也一样 —— BCI 的定义核心就是闭环。

对非侵入产品, 还要追问反馈环节是不是真的回到中枢: 驱动屏幕上的一根进度条, 与给出体感、电刺激或功能性电刺激, 是两种不同的产品。

## 门禁四 阶段与轮次(G0-04)

轮次决定两件事: 证据深度要求与维度权重。种子期看技术真实性与团队, 技术与组织权重上调; B 轮之后看单位经济与注册进度, 商业化、财务、资本权重上调。同一维度在不同轮次的信息价值不同, 一套权重走到底会系统性错配。

## 门禁五 证据可得性(G0-05)

五类硬证据, 覆盖不到三类就不出分级结论:

1. 医疗器械注册证或受理通知书
2. 临床方案、伦理批件与临床报告
3. 专利清单与法律状态(含权属文件)
4. 审计报告或经审计的财务报表
5. 客户合同、中标通知或订单

依据不是口头描述、不是 BP、不是路演。证据覆盖率不足时, 输出的结论应当是「资料不足, 不出结论」而不是「观察」—— 零证据下的低分会被误读为「项目差」, 而它实际只说明「还没开始看」。

## 门禁输出模板

```
资产属性: [五分类之一] | 分类编码: [xx-00] | 适用估值族: [期权+收入 / 器械收入 / 消费品逻辑]
执行维度子集: [全部九维 / 仅 D3+D9]
先补三项证据: 1) ... 2) ... 3) ...
是否终止: [继续 / 仅快筛 / 终止]
```

## 强制终止的三种情形

| 情形 | 处理 | 对应红旗 |
|---|---|---|
| 只有论文或演示, 无任何可运行实体 | 终止完整流程, 只留技术观察记录 | RF-01 |
| 单向监测产品对外称脑机接口 | 终止, 除非对方愿意按监测设备重述业务 | RF-02 |
| 全部证据来自公司自述, 且拒绝提供第三方材料 | 终止, 或先发正式索取清单限期回传 | RF-03 |
